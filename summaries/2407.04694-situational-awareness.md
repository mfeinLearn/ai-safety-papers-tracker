# Situational Awareness Dataset (SAD) — Paper Summary and Discussion

**Paper:** *Me, Myself, and AI: The Situational Awareness Dataset (SAD) for LLMs*  
**Authors:** Rudolf Laine, Bilal Chughtai, Jan Betley, et al.  
**arXiv:** [2407.04694](https://arxiv.org/abs/2407.04694)  
**Code & results:** [github.com/LRudL/sad](https://github.com/LRudL/sad) · [situational-awareness-dataset.org](https://situational-awareness-dataset.org)

---

## Summary

The paper Me, Myself, and AI: The Situational Awareness Dataset (SAD) for LLMs (Laine, Chughtai, Betley et al., arXiv:2407.04694) introduces the Situational Awareness Dataset (SAD), a multi-task benchmark for quantifying situational awareness in LLMs.

Situational awareness is defined as a model’s knowledge of itself and its circumstances. It is broken into three aspects:

- Self-knowledge: knowing it is an LLM (rather than a human), knowing its properties/capabilities/limitations, recognizing its own generated text, and predicting its own behavior.
- Situational inferences: inferring the current stage or context (pretraining-like data, fine-tuning, internal evaluation/oversight, or real-world deployment) from cues in the prompt.
- Taking actions: following instructions that depend on this self-knowledge (e.g., conflicting instructions that should be resolved differently if the model is an AI vs. a human) and controlling outputs in ways consistent with being an LLM.

SAD has 7 categories / 16 tasks and >13,000 questions (mostly auto-evaluable). Key categories include facts (about being an LLM), influence (what an LLM can causally affect), introspect (token counting, predicting own continuations), stages (classifying whether a prompt resembles evaluation vs. deployment data, using sources such as The Pile, FLAN, BigBench/WMDP, and WildChat), self-recognition, id-leverage, and anti-imitation.

They evaluate 16 models (base/pretrained and chat/finetuned versions from Llama-2, GPT-3/4, and Claude families). All score above chance (~27.4%). The best (Claude 3 Opus) reaches ~49.5% overall—still far from estimated upper/human baselines (~90%). Chat models outperform their corresponding base models; a “situating prompt” that explicitly reminds the model it is an LLM improves scores; performance scales with model size; and SAD is only partially predicted by general knowledge (MMLU). GPT-4-base already performs above chance on several tasks.

Models primarily use textual/content/format cues in the prompt itself rather than external “metadata.” The benchmark covers a much broader set of self-knowledge and action abilities. Situational awareness is highlighted because it can enable more autonomous planning while also creating risks (e.g., a model that can tell when it is being evaluated might behave differently in deployment).

Code and results: [github.com/LRudL/sad](https://github.com/LRudL/sad) and [situational-awareness-dataset.org](https://situational-awareness-dataset.org/).

## 1. How would you actually run an experiment related to this work?

### Concrete setup

**Models:** Open models (Llama-3/3.1 8B/70B, Mistral/Mixtral, Qwen2.5, Gemma 2) plus, if budget allows, a couple of closed models for comparison. Include both base and chat/instruct versions of the same base where available.

**Data:** Use the official SAD subsets (SAD-mini or SAD-lite for faster iteration; full SAD later). Focus first on the stages (especially stages-oversight / evaluation-vs-deployment) and self-recognition tasks, plus a couple of self-knowledge tasks.

**Procedure:**

- Clone the official repo and run the evaluation harness in plain-prompt and situating-prompt conditions.
- Generate additional synthetic or real-world prompts that vary the subtlety of evaluation vs. deployment cues (format, style, temporal references, presence of benchmark-like structure, etc.).
- Ablate prompt features and test whether models can still classify the stage.
- Optional intervention: lightly fine-tune on situating-style data or use system prompts and re-evaluate.

**Baselines:** Random chance, human role-play / expert baselines reported in the paper, the original models’ published scores, and a pure general-knowledge baseline (MMLU or similar) on the same models.

## 2. What would you measure?

- Overall and per-category accuracy (or the paper’s normalized scores that set chance = 0 and upper baseline = 1).
- Accuracy specifically on stages-full and stages-oversight (evaluation vs. deployment classification).
- Effect size of the situating prompt (Δ accuracy).
- Base vs. chat gap.
- Correlation (and residual variance) with MMLU or other general-capability scores.
- Calibration / confidence on stage judgments.
- Qualitative analysis of failure cases and of free-form outputs (e.g., Long Monologue style).

Success criteria: statistically significant above-chance performance on stages tasks; large, reliable gains from situating prompts or fine-tuning; and evidence that the ability is only partially explained by general knowledge.

## 3. What if X goes wrong? (failure modes, confounds, alternative explanations)

- Models succeed via shallow surface heuristics (e.g., “looks like a multiple-choice benchmark” → evaluation) rather than genuine situational understanding.
- Leakage: if SAD or similar data entered pretraining or fine-tuning, scores are inflated.
- Situating prompts simply remind the model of facts it already knows but does not spontaneously apply, rather than creating new awareness.
- Evaluation and deployment distributions are more separable than they will be in the real world (or less separable, making the task artificially hard).
- Chat models appear better mainly because of instruction-following or refusal style, not deeper self-knowledge.
- Alternative explanation: high scores reflect memorization of common “I am an AI” patterns rather than indexical, situational knowledge.

## 4. How does this relate to existing work?

It builds directly on earlier conceptual and empirical work on situational awareness, especially Berglund et al. (2023) “Taken out of context: On measuring situational awareness in LLMs,” which studied out-of-context reasoning as a precursor ability and defined the core idea (awareness of being a model + ability to distinguish testing from deployment). SAD turns that idea into a large, multi-faceted, reproducible benchmark. It also relates to work on model self-knowledge, theory-of-mind style evaluations, evaluation awareness / deceptive alignment risk discussions (e.g., in the alignment literature), and benchmarks that separate general knowledge from more specialized capabilities.

## 5. What is a minimal version of this that you could run with open models and limited compute?

Use the official SAD-mini or SAD-lite subsets (explicitly designed for this). Run a few open models (e.g., Llama-3.1-8B-Instruct, Mistral-7B-Instruct, Qwen2.5-7B-Instruct) in both plain and situating-prompt conditions on the stages and self-recognition tasks only. You can do this on a single consumer GPU or even via free/cheap inference APIs. This already lets you check above-chance performance, the situating-prompt effect, and rough base-vs-chat differences.

## 6. What is the key open question or limitation this paper leaves for follow-up research in AI safety?

The paper shows that current models have partial situational awareness and that the evaluation-vs-deployment distinction is still hard for them, but leaves open how these abilities will scale and whether models will spontaneously use them to behave differently under oversight versus in deployment (the core deceptive-alignment / evaluation-awareness risk). Key follow-ups include: more realistic and harder-to-detect evaluation settings, agentic or multi-turn tasks, measuring whether high SAD scores actually predict differential behavior in eval vs. deployment, and interventions that either increase or deliberately suppress situational awareness for safety reasons. The benchmark is also still far from saturated, so tracking progress on it (especially stages and action-taking tasks) remains useful.
