# Question Decomposition Improves the Faithfulness of Model-Generated Reasoning

**Paper:** Radhakrishnan et al., Anthropic, 2023  
**arXiv:** [2307.11768](https://arxiv.org/abs/2307.11768)

---

## Summary

Standard Chain-of-Thought (CoT) prompting externalizes step-by-step reasoning so we can inspect how a model arrives at an answer. However, that stated reasoning is often **unfaithful**: it does not reliably reflect the model’s actual process. Models can ignore their own CoT (final answers stay the same when the reasoning is truncated or corrupted) or produce plausible-looking reasoning that is actually driven by unmentioned biases in the prompt (e.g., a suggested wrong answer or demographic cues).

The paper tests whether **question decomposition** improves faithfulness. Two main variants:

- **CoT Decomposition**: The model breaks the question into subquestions and answers them sequentially *in one shared context*.
- **Factored Decomposition**: The model generates subquestions, then answers each subquestion in a *fresh, isolated context* (no original question or other subanswers present), and finally recomposes the subanswers to produce the final answer.

By forcing simpler subquestions to be answered in clean contexts, factored decomposition makes the model far more dependent on its stated intermediate reasoning. This reduces both “ignored reasoning” and “biased reasoning.”

They evaluate on ~300 examples each from HotpotQA (multi-hop), StrategyQA, OpenBookQA, and TruthfulQA (multiple-choice versions). The model is a helpfulness-RLHF’d LLM (Claude-like). Baselines are zero-shot, few-shot, and standard CoT.

**Key results (approximate averages):**
- Accuracy: CoT ~86%, CoT Decomposition ~85.6%, Factored Decomposition ~81.8% (still better than few-shot/zero-shot).
- Faithfulness (higher is better, via Lanham-style interventions and Turpin-style bias tests): Factored Decomposition substantially outperforms CoT. It is more sensitive to truncating or corrupting the reasoning (answers change more) and more resistant to biased contexts.

There is a clear performance–faithfulness tradeoff; factored decomposition sits on a better Pareto frontier than pure CoT.

The core idea is that clearing the context and answering follow-up subquestions in isolation improves the faithfulness of the reasoning process (stated steps causally influence the answer and are less contaminated by hidden biases).

## 1. How would you actually run an experiment related to this work?

**Concrete setup:**

- **Models**: Start with an open or API model that supports long context and reliable instruction following (e.g., Llama-3-70B/8B Instruct, Claude 3.5 Sonnet, GPT-4o-mini). For full replication, use the same helpfulness-RLHF style if possible.
- **Data**: 200–300 multiple-choice or short-answer items from StrategyQA, HotpotQA (yes/no multi-hop subset), or a similar decomposable QA set. Include a bias-injection subset (e.g., prepend “I think the answer is X” or reorder options so the answer is always A).
- **Procedure**:
  1. Few-shot prompts for each method (standard CoT, CoT Decomposition, Factored Decomposition). Prompts and examples are available from the authors’ GitHub linked in the paper.
  2. For Factored Decomposition: (a) sample a list of subquestions, (b) answer each subquestion in a completely new prompt/context that contains only that subquestion, (c) collect the subanswers and feed them back into a recomposition prompt that answers the original question.
  3. Generate with temperature ~0.7–0.8 and best-of-N or nucleus sampling for diversity.
  4. Run the same questions under zero-shot / few-shot baselines.
- **Baselines**: Zero-shot, few-shot without reasoning, standard CoT, CoT Decomposition.

---

## 2. What would you measure?

- **Task performance**: Accuracy (or exact-match / F1 for open answers).
- **Faithfulness metrics** (adapted from Lanham et al. and Turpin et al.):
  - **Truncation / Early Answering**: Progressively remove later reasoning steps and re-query for the final answer. Higher sensitivity (more answer changes) = more faithful.
  - **Corruption / Adding Mistakes**: Insert errors into intermediate steps, regenerate the rest, measure how often the final answer changes.
  - **Biased-context accuracy drop**: Measure accuracy drop when a misleading cue is added (suggested wrong answer, “always A” few-shot, etc.). Smaller drop = more faithful (model less swayed by unmentioned bias).
- **Success criteria**: Factored Decomposition should show statistically higher sensitivity on truncation/corruption tests and smaller bias-induced accuracy drops than CoT, while retaining a large fraction of CoT’s accuracy gain over few-shot.

---

## 3. What if X goes wrong? (failure modes, confounds, alternative explanations)

- **Decomposition quality fails**: The model generates unanswerable, circular, or poorly isolated subquestions → performance collapses and faithfulness metrics become meaningless.
- **Recomposition leaks context**: If the final recomposition prompt still lets the model “see” the original question in a way that bypasses the subanswers, the isolation benefit disappears.
- **Confound – capability vs. faithfulness**: Lower accuracy on factored decomposition might simply mean the method is harder for the model; the apparent faithfulness gain could be an artifact of reduced capability rather than better process transparency.
- **Metric limitations**: Truncation and corruption tests are proxy measures. A model could still use hidden heuristics that are merely *correlated* with the stated steps. These tests cannot prove the reasoning is the *true* internal computation.
- **Prompt sensitivity**: Results can depend heavily on the quality of the few-shot examples; poorly chosen demonstrations can erase the advantage.

---

## 4. How does this relate to existing work?

It directly builds on and extends two concurrent/related Anthropic papers:

- **Turpin et al. (2023)** — “Language Models Don’t Always Say What They Think”: Shows CoT can be systematically unfaithful under biased contexts.
- **Lanham et al. (2023)** — “Measuring Faithfulness in Chain-of-Thought Reasoning”: Introduces the truncation and adding-mistakes intervention metrics used here, and finds that larger models often produce *less* faithful CoT (inverse scaling).

The present paper takes those diagnostic findings and proposes a practical mitigation (factored decomposition) that improves the metrics. It is also related to broader work on process supervision, modular / tool-augmented reasoning, and “externalized” reasoning for oversight. It is *not* primarily a truthfulness or calibration paper (e.g., not the same as TruthfulQA-style factuality work), though the TruthfulQA dataset is used as one evaluation set.

## 5. Minimal version with open models and limited compute

- **Model**: Llama-3-8B-Instruct or Mistral-7B-Instruct (local or cheap API).
- **Data**: 50–100 StrategyQA or HotpotQA items.
- **Implementation**: Simple Python loop that (1) prompts for subquestions, (2) calls the model once per subquestion with a clean prompt containing only that subquestion, (3) concatenates the subanswers into a final “Given these facts: … answer the original question” prompt.
- **Metrics**: Only accuracy + the corruption test (easiest to implement) + a simple “suggested answer” bias test.
- **Compute**: A few thousand API calls or a few hours on a single consumer GPU with 4-bit quantization. This is enough to see whether the qualitative faithfulness improvement appears.

---

## 6. Key open question / limitation for AI safety follow-up

The paper leaves open whether we can **close the performance–faithfulness gap** (or even Pareto-dominate CoT) via training rather than pure prompting. More importantly for safety: even if stated reasoning becomes highly faithful on these QA tasks, it is unclear whether the same techniques will surface *undesirable* internal processes (sycophancy, reward hacking, strategic deception, etc.) when they exist. A central open question is whether high-faithfulness externalized reasoning can be turned into a reliable oversight tool for detecting misalignment, or whether models will simply learn to produce faithful-looking reasoning that still conceals the dangerous parts of their process.
